Check yours

See which companies in this month's "Who is hiring?" thread fit your public GitHub work, what their users said, and a short draft note. The result is made on your own computer; this page only shows it.

1. Make your result file

Install HN Radar, then run this with your own GitHub username. It reads only your public repositories and writes one file. Nothing is sent anywhere, and the draft is never sent.

uv run hnradar radar YOUR-GITHUB-USERNAME --out radar.json

Privacy: the file you load below is read inside this browser tab. It is not uploaded, not saved in this browser and not sent in any request. Close the tab or use "Clear" and it is gone. Keep the file private: it is about you.
