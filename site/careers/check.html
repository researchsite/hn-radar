Find matches from your GitHub username

Privacy: your browser asks GitHub for your public repositories and matches them with this month's jobs on this page. Only GitHub receives the username, the way any site you visit receives your network address; this site only serves the page and two data files (the jobs, and what their Show HN threads say), which are the same for every visitor and do not depend on your username. Nothing is saved in this browser, no cookie is set and no analytics script runs here. GitHub allows 60 requests an hour from one network address, and 100 repositories per request. A draft note needs a model, so only the command line below writes one.

With the command line, step 1: make your result file

Install HN Radar, then run this with your own GitHub username. It reads only your public repositories and writes one file. Nothing is sent anywhere, and the draft is never sent.

uv run hnradar radar YOUR-GITHUB-USERNAME --out radar.json

Privacy: the file you load below is read inside this browser tab. It is not uploaded, not saved in this browser and not sent in any request. Close the tab or use "Clear" and it is gone. Keep the file private: it is about you.
